# Harbourworks

Small, sharp developer tools for people shipping fast.

**Seaworthy**: a pre-launch security check for AI-built apps. Run it before you ship and get plain-English findings, the exact file and line, and a fix. It runs on your machine, so your code is never uploaded. *In development.*
