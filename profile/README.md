# Harbourworks

**Small, sharp developer tools for people who build fast and ship on their own.**

Harbourworks is the developer-tools workshop of [Dynamo Maritime](https://dynamomaritime.com), an independent software company in the UK. We make focused tools that each do one job properly, for indie builders, small teams and the agencies that ship for them.

## Tools

| Tool | What it does | Status |
| --- | --- | --- |
| [**Seaworthy**](https://dynamomaritime.com/seaworthy) | A pre-launch security check for AI-built apps. Finds leaked keys, open database rules, unprotected API routes, unverified payment webhooks and unsafe LLM code, on your own machine. `npx seaworthy-cli` | Available · [npm](https://www.npmjs.com/package/seaworthy-cli) · [source](https://github.com/harbourworks/seaworthy) |
| [**Soundings**](https://github.com/harbourworks/soundings) | Evidence-backed answers to client security questionnaires, run locally. Scans a project, asks only what the code cannot answer, and drafts privacy notices, subprocessor lists and impact assessments where every statement has a source. `npx soundings-cli` | Pre-release · [source](https://github.com/harbourworks/soundings) |

More tools are in the works.

## How we build them

- **Your code stays yours.** Our tools run where your code lives. We don't upload it, store it or train on it.
- **Free means useful.** Every tool has a free version that does the real work. Paid plans add things like reports and history; they never cripple the free one.
- **Plain English.** Output says what's wrong, why it matters and how to fix it, without a glossary.
- **Few false alarms.** A tool that cries wolf gets switched off, so we test against real-world code and tune for accuracy.
- **Honest about limits.** Our tools are aids, not guarantees. We say what they check and what they don't.
- **Readable source.** Our tools are source-available, so you can see exactly what runs on your machine.
